# Creator Dashboard

An AI-powered Instagram Reels analytics and content planning dashboard built with Next.js 14. It scrapes your reels and competitor reels, transcribes them with Whisper, analyses patterns with GPT-4o, and generates a 30-day content calendar using Claude.

## Features

- **Dashboard** — Quick stats (views, likes, comments, saves), creator score, trending audio, recent reels
- **Reel Ideas** — AI-generated ideas based on your top-performing hook patterns
- **Competitors** — Scrape + transcribe competitor reels, see what hooks/CTAs are working for them
- **Content Calendar** — 30-day calendar generated by Claude with original ideas, hook breakdowns, and body outlines
- **Growth & Analysis** — Detailed pattern analysis: hook types, engagement by hook, CTAs, weaknesses

## Tech Stack

- **Next.js 14** (App Router, Server Components)
- **Tailwind CSS** + **framer-motion** for UI and animations
- **Recharts** for data visualization
- **Apify** — Instagram scraping (`instagram-reel-scraper`)
- **OpenAI** — Whisper for transcription, GPT-4o for analysis
- **Anthropic Claude** — Content calendar generation

## Prerequisites

- Node.js 20.9+
- An [Apify](https://apify.com) account (free tier works)
- An [OpenAI](https://platform.openai.com) account with API access
- An [Anthropic](https://console.anthropic.com) account with API access

## Setup

### 1. Install dependencies

```bash
npm install
```

### 2. Configure environment variables

Copy the example file and fill in your keys:

```bash
cp .env.example .env.local
```

Edit `.env.local`:

| Variable | Description |
|---|---|
| `APIFY_API_TOKEN` | Your Apify API token (from console.apify.com/account/integrations) |
| `OWN_INSTAGRAM_USERNAME` | Your Instagram handle without @ |
| `COMPETITOR_HANDLES` | Comma-separated competitor handles without @ |
| `OWN_REELS_LIMIT` | How many of your reels to scrape (30–50 recommended) |
| `OPENAI_API_KEY` | OpenAI API key (used for Whisper + GPT-4o) |
| `ANTHROPIC_API_KEY` | Anthropic API key (used for Claude calendar generation) |
| `CREATOR_*` | Optional creator profile fields used in prompts and the sidebar |
| `API_AUTH_TOKEN` | Optional token for protected job/write routes |
| `CREATOR_DASHBOARD_URL` | Local URL used by the scheduled worker script |

### 3. Run the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## First-Time Usage

1. **Run setup** — Open `/setup`, enter your Instagram handle and competitors, then start the analysis. This pulls your latest reels from Instagram via Apify, transcribes the audio with Whisper, and runs GPT-4o analysis. Takes ~5–10 minutes depending on reel count.

2. **Scrape competitors** — Go to **Competitors** and click "Analyse Competitors". This scrapes each competitor's reels, transcribes them, and extracts their hook/CTA patterns. Takes ~5–10 minutes.

3. **Generate calendar** — Go to **Calendar** and click "Generate with Claude". Claude reads your analysis + competitor patterns and generates 30 days of original reel ideas.

## Streamlined Bot Architecture

The expensive work is centralized in `lib/jobs.ts` and protected by a filesystem lock under `data/locks/`. Both `/api/setup` and `/api/jobs/analyze` use the same job runner, so overlapping runs do not duplicate scraping or spend extra API credits.

For a systemd/FraqtoOS deployment:

```bash
npm run build
sudo cp ops/creator-dashboard.service /etc/systemd/system/
sudo cp ops/creator-analysis-worker.service /etc/systemd/system/
sudo cp ops/creator-analysis-worker.timer /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now creator-dashboard.service
sudo systemctl enable --now creator-analysis-worker.timer
```

The scheduled worker calls `/api/jobs/analyze`, which lets the dashboard stay responsive while the worker handles scrape/transcribe/analyse runs on a timer.

## Data & Privacy

All scraped data is stored locally in the `data/` directory as JSON files. Nothing is sent to any external service beyond:
- Apify (for Instagram scraping)
- OpenAI (reel audio for transcription + analysis)
- Anthropic (analysis summary for calendar generation)

The `data/` directory is git-ignored and should never be committed.
